# House-Price-Prediction

Linear Regression model to predict house prices using Ames Housing dataset.

#Steps
-1 Data Cleaning & One-Hot Encoding (pd.get_dummies)
-2 Train-Test Split (80-20)
-3 Model: Linear Regression

## Results
- R2 Score: 0.619
- Adjusted R2: 0.570
- Features: 33 after encoding

Dataset from Kaggle - House Price Prediction.
